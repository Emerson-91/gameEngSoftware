=============================================
  MÚSICAS DAS FASES - GAME ENG. SOFTWARE
=============================================

O jogo possui um sintetizador de áudio retro integrado via Web Audio API 
que gera e toca músicas e efeitos de forma automática e 100% offline.

SE VOCÊ DESEJAR USAR ARQUIVOS MP3 CUSTOMIZADOS:
Basta colocar seus arquivos de áudio .mp3 nesta pasta com os seguintes nomes:
  - fase1.mp3
  - fase2.mp3
  - fase3.mp3
  - fase4.mp3
  - fase5.mp3
  - fase6.mp3
  - fase7.mp3
  - fase8.mp3

Se o jogo encontrar os arquivos MP3, ele os tocará automaticamente! 
Caso contrário, usará o sintetizador chiptune retro integrado.
